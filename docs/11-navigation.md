# 11. Navigation

Six groups, so the menu still fits on a phone. The mockups show this menu.

| Group | Screens inside |
|---|---|
| Ask | Chat |
| Library | Archives, manuals and books, emergency cards |
| Maps | Map, drawing, saving, exporting |
| Music | Library (search, artists, albums, folders), Queue, Playlists, Equalizer. A small player bar stays at the bottom of every screen while a song is loaded. |
| Plan | Start, Inventory, Drills, Family, Binder, What fails next |
| Settings | Downloads (satellite counties), Devices, Sources and licenses, language, passphrase lock, Android layout notes |

On a phone the six groups become a bottom bar. On a computer they sit across the top, with the screens of the current group underneath.

The footer keeps the honest status line: model, speed, memory, "this app only talks to itself".
