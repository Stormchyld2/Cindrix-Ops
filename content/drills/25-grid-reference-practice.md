title: Read and plot grid references
minutes: 30
where: at home with a map
summary: Read six-digit references from the map, and find places from them.
status: draft
---
Do each step for real, do not just read it.
- Pick six features on the map and write their six-digit grid references
- Swap with a partner and find each other's features
- Check every answer against the map
- Say each reference aloud in two groups of three digits
- Fix any mistakes about right-then-up
