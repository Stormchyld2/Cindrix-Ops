Photos for the cards go here (JPEG, PNG or WebP, about 800 px wide, under 1.5 MB each).

To put a photo on a card, add one line to the card's header with the file name only:

    image: morel.jpg

The card shows the photo only when it names one and the file is in this folder. A card with no `image:` line, or
whose file is missing, looks exactly as it did before. The same names are also looked for in the drive's `images`
folder and in `user/images` (your own copy wins over a shipped one). See licenses/README.md before sharing any drive.
