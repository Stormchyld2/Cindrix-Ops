**Most handheld radios can store dozens of channels. Set them up once, at home, before you need them.**

**The settings that matter:**
- **Frequency:** the number you tune to (for example 462.5625 MHz).
- **Mode:** FM for almost all voice use in handhelds.
- **Power:** high or low. Use low power when the other station is close; it saves the battery.
- **Squelch:** the control that cuts the hiss when no one is talking. Turn it up until the hiss stops.
- **Tone (CTCSS/DCS):** a quiet tone that opens the other radio's speaker only when it matches. Set to "off" to hear everything on the channel. Repeaters usually need a specific tone to open. **A tone is not security.**
- **Offset:** a repeater listens on one frequency and re-sends on another. The radio needs the shift (for example, minus 0.6 MHz for 2 m) to talk through it.
- **Bandwidth:** wide (25 kHz) or narrow (12.5 kHz).

**Make a memory plan:**
1. **Channel 1:** the family channel.
2. **Channel 2:** a backup channel.
3. **NOAA weather:** 162.550 MHz.
4. **Local repeaters** you can use (ham or GMRS).
5. **Simplex calling channels:** 146.520 MHz and 446.000 MHz (for hams).
6. **Emergency channels** for FRS/GMRS/MURS/CB.

**Programming by computer:** a free program called **CHIRP** can copy settings between radios of many makes and models with a programming cable. It saves a lot of typing. Save the file in a safe place, and print the list.

**Label each radio** with the channel list, so an unfamiliar person can use it.

**Lock the keypad** so buttons are not pressed in a bag.

**Practise** changing channels with your eyes closed.

Source: Typical handheld radio manuals and the free CHIRP programming software documentation. Menus differ between models; use your radio's manual. Not yet reviewed.
