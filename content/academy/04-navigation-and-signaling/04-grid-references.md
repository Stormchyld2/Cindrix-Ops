A six-digit grid reference names a spot to within about 100 metres.

## The rule: right, then up
1. Find the number of the vertical grid line just **left** of the spot (the easting) and estimate how many tenths across the square the spot is.
2. Find the number of the horizontal grid line just **below** it (the northing) and estimate the tenths up.
3. Join them: three digits for across, three for up.

## Example
Vertical line 43, six tenths across: **436**. Horizontal line 77, two tenths up: **772**. The reference is **436772**, said "four three six, seven seven two".

## Common mistakes
- Reading **up before right.**
- Using the line **to the right** instead of the one to the left.
- Forgetting to estimate the tenths.

> Say the digits out loud in two groups of three. If someone reads them back wrong, you find out before it matters.
