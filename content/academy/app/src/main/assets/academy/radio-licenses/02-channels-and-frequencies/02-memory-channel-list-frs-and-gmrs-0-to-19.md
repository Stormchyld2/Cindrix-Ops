A memory channel list is a plan for programming your radio so that everyone in your group has the same channel on the same number. This list has 99 memory channels, numbered 0 to 98. This lesson covers the first twenty, which are the license-free FRS channels and the GMRS channels. The next lesson covers the rest.

> The picture this list was made from does not show channels 20 to 30 or 51 to 61. Use those for your own local repeaters and agreed group channels (see the Comms PACE plan in the Communications course).

## Who may transmit
- FRS needs no license. GMRS needs the license described in the first lesson of this course.
- Listening is always allowed. Transmit only on a service you are licensed for or that needs no license.

? Why keep the same memory channel list in every group radio?
+ So everyone has the same channel on the same number
- So the radios use more power
- So you do not need a license
- So the batteries last longer
> A shared list means that when you say 'channel 3', everyone is on the same frequency.
