## Series
Parts connected in a single chain. **Current is the same everywhere, and voltages add up.** Resistances add: R = R1 + R2 + … If one part breaks, the circuit stops (as in cheap string lights).

## Parallel
Parts connected side by side across the same two points. **Voltage is the same on each branch, and currents add up.** If one branch fails, the others keep working (as in household outlets).

## Fuses and breakers
A fuse or breaker is a deliberate weak link: it opens the circuit when current gets too high, before wires overheat. **Replace a blown fuse with the same rating, never a bigger one.** Find out why it blew first.

## Check yourself
? In a series circuit, which stays the same?
+ Current
- Voltage
- Resistance
- Power
> There is only one path.
? Why are fuses rated?
+ To open the circuit before the wire overheats
- To look good
- To store power
- To increase current
> Using a larger fuse removes that protection.
? In a parallel circuit, what stays the same across branches?
+ Voltage
- Current
- Resistance
- Color
> Each branch sees the same voltage.
