**PRIMARY Comms Methods** — Normal communication
(Cell Towers UP, Internet UP, Power Grid UP)

• Cell Phone: If a phone call is not going through, send a text.

• Send a message on Signal — you should have an "EMERGENCY TRAFFIC" channel set up.

• If the Signal app is down, try reaching your local Comms Specialist.

• CS shall establish a group text using SMS through your cell carrier.

• Sustainment "unsecure" communications only. For use in non-tactical situations. Use code words to protect sensitive information.
