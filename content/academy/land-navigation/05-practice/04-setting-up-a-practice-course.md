A course tests your skills before you must rely on them. Set one up once or twice a year and practice again, because navigation skills fade fast.

## Plan it
- Teach before you test: map reading, compass work, pace count, then dead reckoning, then terrain association.
- Test in the field and on paper.
- Start with a simple course for beginners and make it harder over time.

## Pick the ground
- Use ground like the ground you might have to cross.
- Change the area from time to time so people don't memorize it.
- Visit it first to check for hazards, and plot the marker positions on a map.

## Suggested limits (scale them for your group)
The army guide uses 7 to 9 markers per lane, 300 to 1,200 meters between markers, a total of 2.7 to 11 km, and three to four hours. For a family or small group, use fewer markers and shorter legs:
- 4 to 6 markers.
- 100 to 400 meters between them.
- An hour or two, with a clear return time.

## Make the markers
A marker can be a painted milk jug, a bucket or a stake with a card. Each should have a code or a way to prove you were there (a stamp, a coded letter, different color crayon).

## Write a clue sheet
For each marker give its grid reference (or sketch), a code, and a short description. Keep it secret until the start. Give each person a map, a compass, a pencil and a score card with name, start time, finish time and a block for each marker.

## Safety
- Test the course yourself first.
- Write down the safety direction, the boundary, the return time, and a place for a first aid kit.
- A whistle for each person.
- If anyone has not returned by the time, search along the boundary roads.

## Score it
Points for finding each marker; points off for late return; compare routes afterwards. The chance to compare is the most important learning.

## Skill ladder
1. Read the map and say where you are.
2. Take and follow a bearing.
3. Pace a known distance.
4. Walk a route using handrails and catching features.
5. Find a point using an attack point.
6. Do it in poor light.

> If you can do all of these without help, you have the skills in this course.
